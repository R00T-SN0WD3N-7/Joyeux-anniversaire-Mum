SITE SURPRISE D'ANNIVERSAIRE POUR MUM
====================================

FICHIERS
- index.html : contenu du site
- style.css  : apparence et adaptation téléphone/ordinateur
- script.js  : musique, bouton de démarrage et diaporama
- photos/    : place ici les photos de Mum avant de publier
- audio/     : place ici la musique d'anniversaire

PERSONNALISER LES PHOTOS POUR QUE TOUT LE MONDE LES VOIE
1. Ouvre le dossier photos.
2. Ajoute tes images et nomme-les photo-1.jpg, photo-2.jpg, photo-3.jpg, etc.
3. Dans index.html, la première image est indiquée par photos/photo-1.jpg.
4. Pour un diaporama partagé sur Internet, il faut que les photos soient ajoutées au code/site avant la publication. Le bouton « Ajouter mes photos » sert seulement à tester des photos localement sur ton appareil : les photos choisies de cette façon ne sont pas envoyées sur le site et les visiteurs ne les verront pas.

MUSIQUE
1. Ajoute un fichier audio que tu as le droit d'utiliser dans le dossier audio.
2. Nomme-le exactement anniversaire.mp3.
3. Sur un téléphone, la musique commence après le clic sur « Découvrir ma surprise ». Certains navigateurs peuvent bloquer la lecture si le fichier audio manque ou n'est pas lisible.

TESTER SUR TON ORDINATEUR
Ouvre index.html dans un navigateur. Pour le meilleur résultat, utilise un navigateur récent.

PUBLIER GRATUITEMENT AVEC GITHUB PAGES
1. Crée un compte sur https://github.com/ si tu n'en as pas.
2. Crée un nouveau dépôt public, par exemple surprise-pour-mum.
3. Téléverse index.html, style.css, script.js et les dossiers photos/ et audio/ avec leurs fichiers.
4. Dans le dépôt, va dans Settings > Pages.
5. Sous Build and deployment, choisis Deploy from a branch, sélectionne la branche main et le dossier /(root), puis Save.
6. Attends la publication. GitHub indiquera une adresse ressemblant à https://TON-PSEUDO.github.io/surprise-pour-mum/
7. Ouvre le lien sur ton téléphone pour vérifier le site, puis partage-le dans WhatsApp.

IMPORTANT
- N'inclus que des photos que tu as l'autorisation de partager.
- Utilise une musique libre de droits ou dont tu possèdes les droits.
- Le bouton d'ajout de photos local n'envoie rien sur Internet. Pour que les photos apparaissent chez Mum, elles doivent être intégrées dans le dossier photos avant la mise en ligne.
